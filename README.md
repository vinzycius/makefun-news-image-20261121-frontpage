A program that draws a newspaper front page summing up Saturday 21 November 2026's world news — 45 stories across 7 regions and 16 fields, every one verified as happening or first reported on Saturday 21 November 2026, with a six-number strip, a UTC timeline, a world map with numbered pins, and a DATE CHECK box naming the date errors in rival entries.

## Run it

```sh
python3 main.py
```
